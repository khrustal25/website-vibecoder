# website-vibecoder

Персональный лендинг-портфолио вайбкодера.

Сайт о Елене Хрусталевой: услуги, процесс работы, проекты и форма заявки. Сейчас проект готовится к загрузке в репозиторий GitHub.

Одностраничный сайт на чистых HTML, CSS и JavaScript. Без фреймворков, без сборки и без backend.

## Разделы сайта

На главной странице есть:

1. **Первый экран (hero)** — имя, заголовок, краткое описание и кнопки «Обсудить проект» / «Посмотреть работы»
2. **Обо мне** — текст и факты
3. **Услуги** — карточки: сайты и лендинги, веб-сервисы, чат-боты и AI, автоматизация
4. **Как работаю** — шаги от идеи до запуска
5. **Проекты** — портфолио:
   - «Чек-лист задач»
   - «Конструктор ТЗ в Telegram для создания каруселей» (со ссылкой на проект)
   - карточки «Проект 03» и «Проект 04» — пока заготовки «Проект в разработке»
6. **Преимущества** — список сильных сторон
7. **Контакты** — кнопки Telegram / почта / VK и форма заявки
8. **Подвал** — контакты, ссылка на политику конфиденциальности, год

Отдельная страница: **`privacy.html`** — политика конфиденциальности.

## Технологии

- HTML
- CSS (в том числе адаптивная вёрстка)
- JavaScript (меню, плавный скролл, анимации появления блоков, проверка формы)
- Google Fonts: Playfair Display и Montserrat

Сервера и баз данных нет. Форма заявки проверяется в браузере и открывает письмо через `mailto`.

## Как запустить локально

### Способ 1. Просто открыть файл

1. Откройте папку проекта.
2. Дважды щёлкните по файлу `index.html`.
3. Сайт откроется в браузере.

Чтобы всё работало корректно (стили, картинки, ссылки на `privacy.html`), рядом должны лежать `styles.css`, `script.js` и папка `images/` с нужными файлами.

### Способ 2. Локальный сервер (удобнее для проверки)

В терминале перейдите в папку проекта и выполните:

```bash
python -m http.server 8080
```

Затем откройте в браузере: `http://localhost:8080`

Страница политики: `http://localhost:8080/privacy.html`

Сохраните новую фотографию с тем же именем — она подставится автоматически. Удобнее использовать горизонтальный кадр примерно 16:9.

В `index.html` в блоке проектов можно заменить:

- изображение (положите файл в `images/` или `images/projects/` и обновите путь в `src`)
- категорию, название и описание
- ссылку на проект (если она есть)
- статус карточки

### Форма заявки

Форма проверяет:

- имя
- способ связи
- контакт
- обязательное согласие на обработку персональных данных

Серверной отправки нет: после успешной проверки открывается почтовая программа с готовым письмом (`mailto`). Если письмо не открылось, на экране остаётся кнопка «Написать в Telegram».

## Адаптив

Вёрстка рассчитана на разные ширины экрана, в том числе примерно:

- 1440 px
- 768 px
- 375–390 px

Есть мобильное меню (бургер).

## Важно перед загрузкой в репозиторий

В репозиторий имеет смысл класть только рабочие файлы сайта (список в разделе «Структура файлов»).  
Черновики, референсы и старые фото из папки `images/` загружать не обязательно.
